# Monge CAD — Claude plugin

Connects Claude to the Monge CAD MCP server (search standard parts, interactive 3D view, STEP/STL/3MF/GLB with SHA-256) and adds the `monge-cad` skill.

- Server: see `.mcp.json` (no authentication, read-only).
- After installing: open the plugin's **Connectors** tab and add / connect `monge-cad`.
