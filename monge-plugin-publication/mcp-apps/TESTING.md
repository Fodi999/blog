| Инструмент | `render_model_viewer {id, compare_with?, layout?, locale?}` — id модели или размера без исполнения (`bolt-iso-4017--m12-x-60` → настоящая резьба); до трёх моделей для сравнения; `layout: "side_by_side"` — сразу рядом |

| Просмотр | вращение, масштаб, сдвиг, «Сбросить вид», «Во весь экран»; переключатель исполнений (настоящая / косметическая / для печати); вкладки и «Рядом» для нескольких моделей в настоящем масштабе |

| Без MCP Apps / без WebGL | текст: характеристики, WebP (с пометкой), файлы с SHA-256, ссылка на 3D-просмотр на сайте; в окне — WebP, данные и ссылка |

## Как проверить в ChatGPT (Web и Desktop)

1. ChatGPT в браузере → **Настройки → Apps & Connectors → Advanced settings → Developer mode** — включить (нужен тариф, где режим разработчика доступен).
2. **Create / Add connector**: имя `Monge CAD (test)`, URL — приватный адрес выше, **No authentication**.
3. Новый чат → выбрать коннектор (через «+» / Developer mode) и спросить:
   - «Покажи в 3D болт ISO 4017 M12×60 с настоящей резьбой.»
   - «Покажи болт M12×60 и гайку к нему рядом.»
   - «Show the 6204-2RS bearing in 3D, full screen.»
   - «Pokaż nakrętkę M8 do druku 3D w 3D.»
4. Ожидается: под ответом **сам появляется окно 3D** (без открытия GLB по ссылке), модель вращается мышью, кнопки «Сбросить вид» и «Во весь экран» работают, ссылки STEP/STL/3MF/GLB открываются, для болта с гайкой — вкладки и «Рядом».
5. ChatGPT Desktop (macOS/Windows) — тот же аккаунт: коннектор подтягивается; повторить вопросы 3.
6. Если вместо окна только текст — ChatGPT не отрисовал шаблон: пришли снимок экрана и текст ответа. Если окно пустое — пришли снимок; вероятная причина — CSP/загрузка GLB.
